# Arapongas Digital

Plataforma/PWA para descoberta do comércio local de Arapongas, preparada para expansão multi-cidade.

## Arquitetura
- Frontend mobile-first / PWA
- Neon PostgreSQL
- Neon Auth
- Neon Data API
- Deploy planejado na Vercel

## MVP
Home, busca, categorias, ofertas, produtos/serviços, geolocalização, página da loja/produto, painel do comerciante e posteriormente Painel Master.

> Dados comerciais exibidos nesta primeira interface são demonstrativos. Informações reais serão provenientes do cadastro dos comerciantes.
